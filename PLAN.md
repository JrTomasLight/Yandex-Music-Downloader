# План разработки

Цель первой версии (0.1.0): вошедший пользователь нажимает «Скачать» на странице альбома, плейлиста или исполнителя
Яндекс Музыки — и треки, доступные ему по подписке, оказываются в выбранной папке, с понятными именами, тегами
и обложкой; повторное нажатие докачивает только новое. Сделанное отмечать `[x]`.

## Этап 1. Разведка сайта — сделано (ноябрь 2026, под входом пользователя)
- [x] Адреса нового интерфейса: `/album/<id>`, `/album/<id>/track/<id>`, `/artist/<id>`, `/playlists/<uuid>`
      (в том числе «Мне нравится» — `/playlists/lk.<uuid>`), `/collection`. Учтено в `parseLink`.
- [x] API — `api.music.yandex.ru`, вход по cookie сайта (`credentials: include` из вкладки сайта). Ответы описаны
      в разделе «API сайта» в `CLAUDE.md`.
- [x] **Решающая точка пройдена:** `download-info?direct=true` отдаёт подписчику прямую ссылку на обычный mp3
      до 320 кбит/с (файл начинается с кадра MPEG, без шифрования). Защищённые потоки плеера (`encraw`) не используем.
- [x] Недоступные треки: `available: false` в описании, `403 no-rights` на ссылке — пропускаются с объяснением.
- [ ] Как сайт отвечает на очень частые запросы — проверить на больших плейлистах (обработка 429 уже есть).
